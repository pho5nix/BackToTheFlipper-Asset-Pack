## Install

1. Make sure you're on **Momentum Firmware**.
2. Open **qFlipper**, go to **SD Card → `asset_packs`**.
3. Unzip `BackToTheFlipper.zip` and drag the entire `BackToTheFlipper/` folder into `SD/asset_packs/`.
   - Verify you end up with `SD/asset_packs/BackToTheFlipper/Anims/` and `SD/asset_packs/BackToTheFlipper/Icons/`.
4. On your Flipper:
   - From the home screen, press **UP** then open **Momentum Settings** (the MNTM app).
   - Navigate: **Interface → Graphics → Asset Pack**.
   - Use **left/right** to select **BackToTheFlipper**.
5. Exit the app, your Flipper will reload and use the BTTF assets.
